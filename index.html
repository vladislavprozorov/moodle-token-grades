Таблица отметок студента по токену

Страница получает токен веб-сервиса Moodle и по нему через REST API показывает оценки по всем курсам, на которые вы записаны. Данные отправляются только на указанный сайт Moodle.

У меня уже есть токен

Шаг 1: страница отправляет логин и пароль в login/token.php вашего Moodle и получает токен. Шаг 2: по токену вызывает REST API и строит таблицу. Пароль и токен никуда не сохраняются.

Используемые функции: login/token.php, core_webservice_get_site_info, core_enrol_get_users_courses, gradereport_user_get_grade_items. Автор: Владислав Прозоров.
